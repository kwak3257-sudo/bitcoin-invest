# 코인 투자 도우미

빗썸(이후 업비트)과 연동하는 한국어 비트코인·알트코인 투자 프로그램입니다.
기획서: https://claude.ai/artifact/AJRv9PBS134jSbLNFDgrJx

## 지금 들어 있는 것 (1단계)

- 빗썸 API 2.0 연동: 원화 마켓 목록, 현재가, 캔들(1분~월봉), 잔고 조회, 시장가 매수
- 주간 정기 매수 전략: 요일·시각(KST)·금액·코인·누적 한도 설정, 기본값 꺼짐, 모의투자/실거래 선택
- 목표 수익 매도: 매수·매도 수수료를 모두 빼고도 평균 단가보다 목표 % 이상 오르면 보유량 일부 매도
- 수익 분석 화면: 투자 원금, 평가 금액, 실현·미실현 손익, 수익률, 낸 수수료, 손익 흐름 차트, 거래 기록
- 매매 엔진: API 서버와 별도 프로세스로 실행, 같은 주에 두 번 매수하지 않음
- 한국어 웹 화면: 대시보드(관심 코인 시세, 캔들 차트), 자동매매 설정. 휴대폰 화면 대응
- 백테스트: 이동평균 교차 + RSI 단기 전략을 과거 캔들로 돌려 수수료·슬리피지를 뺀 성과를 "그냥 보유"와 비교
- 단기 매매 자동 운영: 백테스트와 같은 전략을 봉이 끝날 때마다 실행. 운용 금액 한도, 손절·익절,
  하루 손실 한도(넘으면 보유분을 팔고 다음 날 0시까지 쉼), 긴급 정지 버튼, 텔레그램 알림

## 구조

```
backend/   Python FastAPI API 서버 + 매매 엔진
  app/exchanges/   거래소 어댑터 (공통 인터페이스 base.py, 빗썸 bithumb.py)
  app/strategies/  매매 전략 (주간 정기 매수 dca.py, 단기 신호 short_term.py, 단기 자동 운영 trader.py)
  app/backtest.py  백테스트
  app/engine.py    매매 엔진 (python -m app.engine)
  app/main.py      API 서버
frontend/  React + TypeScript 화면 (Vite)
```

## 윈도우 PC에서 실행

1. 파이썬 3.13 (3.14 이상은 아직 일부 라이브러리가 설치되지 않음. setup.bat이 없으면 3.13을 설치함), Node.js LTS, Git을 설치합니다.
2. `setup.bat`을 더블클릭합니다. 끝나면 `.env` 파일에 빗썸 API 키를 넣습니다.
3. `start.bat`을 더블클릭하면 API 서버, 매매 엔진, 화면이 켜지고 브라우저가 열립니다.
4. 새 버전이 나오면 `update.bat`을 더블클릭합니다. 켜져 있던 프로그램을 끄고, 새 버전을 받고, 다시 켭니다.
   끄기만 하려면 `stop.bat`을 더블클릭합니다.
5. 빗썸 키와 텔레그램 알림은 `connect.bat`을 더블클릭해 한 번에 연결합니다. 화면 안내대로 붙여 넣기만 하면 되고, 키는 이 PC의 `.env`에만 저장됩니다.
6. 휴대폰 텔레그램에서 내 봇에게 `/상태`를 보내면 수익률, 보유 현황, 매수 조건 분석을, `/정지`를 보내면 긴급 정지합니다. 내 텔레그램에서 보낸 명령에만 답합니다. 봉이 끝날 때마다(일봉이면 하루 한 번) 분석 요약을, 매일 오전 9시에 브리핑을, 엔진이 켜질 때 켜짐 알림을 보냅니다.

### 텔레그램 알림 켜기 (선택)

1. 텔레그램에서 `@BotFather`에게 `/newbot`을 보내 봇을 만들고 토큰을 받습니다.
2. 만든 봇에게 아무 메시지나 보낸 뒤, 브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates`를 열어 `"chat":{"id":` 뒤의 숫자를 찾습니다.
3. `.env`의 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`에 넣고 `start.bat`을 다시 실행합니다.

## 직접 실행 (맥, 리눅스)

```bash
# 1) 백엔드
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
cp ../.env.example ../.env   # 키를 넣고 환경 변수로 불러오기
uvicorn app.main:app --reload          # API 서버 (http://127.0.0.1:8000)
python -m app.engine                   # 매매 엔진 (다른 터미널)

# 2) 화면
cd frontend
npm install
npm run dev                            # http://localhost:5173
```

## 테스트

```bash
cd backend && pytest
cd frontend && npm run build && npm run lint
```

## 안전 수칙

- 실거래로 켜져 있는 설정을 저장하려면 텔레그램으로 온 인증번호 6자리를 넣어야 합니다(5분 유효, 5번 틀리면 취소).
  텔레그램을 설정하지 않으면 실거래를 켤 수 없습니다. 끄기와 긴급 정지는 인증 없이 바로 됩니다.
- 설정이 저장될 때마다 텔레그램으로 알림이 갑니다. 내가 하지 않은 변경 알림이 오면 PC의 프로그램 창을 모두 닫으세요.
- 서버와 화면은 이 PC 안(127.0.0.1)에서만 열립니다. 공유기 포트 포워딩이나 원격 접속 프로그램으로 밖에 열지 마세요.
- 빗썸 계정에는 OTP(2단계 인증)를 켜고, 윈도우에는 로그인 비밀번호를 걸어 둡니다.

- API 키는 출금 권한 없이 발급하고, 빗썸에 서버 IP만 허용합니다.
- `.env`는 저장소에 올리지 않습니다.
- 실거래는 모의투자로 충분히 돌려 본 뒤 작은 금액으로 시작합니다.
- 빗썸 최소 주문 금액(5,000원)과 API 응답 형식은 공식 문서(https://apidocs.bithumb.com)로 다시 확인해야 합니다.
